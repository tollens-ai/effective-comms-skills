# Comms Review — make the draft ready to deliver

Fix concrete content defects within the user's request, preserving source meaning and applying
their house style. The whole delivery matters: titles, headings, links, returned files, and the
accompanying chat message.

## Choose the review needed

**Cosmetic correction after review.** For an already reviewed draft, proofread a typo, spelling,
or formatting correction locally and deliver it, unless a broader review was explicitly requested.
Check the effect, not the edit's size: a one-character change to a number or negation can change
meaning and belongs on the content-review path below.

**Initial or substantive review.** Use the audience and source preparation from `/comms-prep`.
If it is missing or no longer fits, use that skill's quick-check or written-brief path. Then read
[Content checks](references/content-checks.md) and review the complete delivery. Fix supported
issues within your authority; recheck changed meaning against sources. After substantive edits to
reviewed text, revisit the affected checks rather than restarting unrelated checks.

**Independent audience review.** When preparation calls for it, read
[Audience review](references/audience-review.md) and carry it out after the content review. It tests
comprehension and usefulness; the author remains responsible for source accuracy. An explicit
request for `/comms-review` gets content review but does not by itself require an independent agent.
An explicit request for independent review does.

## Complete the delivery

Finish when the communication serves its objective, source checks hold, and no known material
reader problem remains. If a material fact or choice requires someone else's input, use available
sources and existing authorization first, then ask a concrete question only where needed. Continue
unaffected work; if full completion is impossible, deliver the useful portion with its specific
limit. A review count does not create an approval requirement.

Later changes to claims, numbers, recommendations, scope, or structure reopen the affected content
and source checks. Repeat independent review when a change could materially affect the reader's
understanding or action and the communication warrants that depth. Cosmetic changes need local
proofreading.

Return the requested communication. Keep briefs, reviewer prompts and returns, superseded drafts,
and review notes in working state unless audit or provenance is explicitly requested.

The chat handoff says what was delivered and any material limit. It does not describe the review
that produced it, claim a pass that did not happen, or imply that something was built when only a
specification was written. Apply the same checks to handoff text added at finalization.

## Maintainer reference

The content rubric lives in [Content checks](references/content-checks.md).

the standard owner's decision. Do not redesign the standard through an extension.
