# Effective Comms: pick the next action

Use the first matching row, then complete that action.

| State | Do |
|---|---|
| Underlying work is still producing the substance | Stay with that work. Preparation is due when the substance is ready. |
| Ready to write a one-line acknowledgement or direct yes/no answer | Write it. No gate is due. |
| Audience and source preparation is missing or no longer fits | Run `/comms-prep` using its quick-check or written-brief path. If a draft already exists, prepare from the request and intended purpose, then review it at the chosen depth, honoring explicit review requests. Otherwise draft and follow the review decision. |
| Preparation still fits and no draft exists | Draft from it and follow its review decision. |
| A draft exists and the preparation calls for independent audience review, or the user explicitly requests `/comms-review` | Run `/comms-review`. |
| A draft exists and self-review is sufficient | Self-review for reader fit, source fidelity, and applicable style; fix concrete defects, recheck changed meaning, then deliver. |

`/comms-prep` defines preparation and review depth; `/comms-review` carries the detailed content
checks and audience review. Reuse fitting preparation across routine follow-ups. Neither the
router nor a review count creates a new need for user approval.
